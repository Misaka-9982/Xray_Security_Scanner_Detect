# X 光安检目标检测

基于 **YOLOv5 + PyQt5** 的桌面目标检测程序，通过图形界面加载本地图片或视频，展示检测框、目标类别与置信度。

## 基本功能

- **图片检测**：显示检测结果图，并按置信度排序列出识别到的目标。
- **视频检测**：后台逐帧推理与播放，支持停止识别，结束后汇总每类目标的最高置信度。
- **模型与参数选择**：在界面中选择 `.pt` 模型权重，调整置信度阈值。
- **中文结果展示**：提供枪支、刀类、钳子、剪刀、扳手、电池/充电宝、打火机七类目标的中文名称映射。

推理在后台线程执行，通过 Qt 信号和帧缓冲队列更新界面。

## 运行方式

在仓库根目录安装依赖并启动：

```bash
pip install -r requirements.txt
python main.py
```

进入图片或视频模式，选择模型权重，再打开待检测文件。

程序默认使用通用的 `yolov5s.pt`；检测 X 光安检目标需加载对应的训练权重。训练权重和数据集未随仓库提供。

## 主要文件

- `main.py`：界面交互、检测调用与视频播放。
- `UI/`：Qt Designer 界面文件及生成代码。
- `detect.py`：YOLOv5 推理与界面结果传递。
- `DataSetProcess/`：标注格式转换、空标签生成与数据集划分。

## 项目来源

检测模型与训练代码基于 [Ultralytics YOLOv5](https://github.com/ultralytics/yolov5)。本项目在其基础上增加 PyQt5 图形界面、检测结果展示和视频播放交互。
